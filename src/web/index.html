How this works & your privacy

Consent-first. The synthetic living-room sensor only produces observations while capture is enabled and consent is granted. Withdraw either and the gate blocks all delivery — nothing reaches the event pipeline.

Local & private. Everything runs on this machine. No cloud, no network calls, no raw audio/video. Only alert metadata (id, severity, rule, timestamp) is stored, in a local SQLite database.

Real backend. Observations flow through the actual C++ event pipeline: validation → time-window correlation → alert dedup/cooldown → durable persistence. The numbers below come from that running code, not from this page.
