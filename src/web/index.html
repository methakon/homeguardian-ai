How this works & your privacy

Consent-first. The synthetic household sensor only produces observations while capture is enabled and consent is granted. Withdraw either and the gate blocks all delivery — nothing reaches the event pipeline.

Local & private. Everything runs on this machine. No cloud, no network calls, no raw audio/video. Only alert metadata (id, severity, rule, message, timestamp) is stored, in a local SQLite database.

Real backend. Observations flow through the actual C++ event pipeline: validation → time-window correlation → alert dedup/cooldown → durable persistence. Every number and message below comes from that running code, not from this page.

Reading the result

Detected / not detected / inconclusive are the detector's own verdicts on the synthetic evidence — an inconclusive result is never reported as a detection.

Fusion combines detector outputs; when evidence is ambiguous or insufficient it reports inconclusive or unavailable rather than inventing confidence.

Alerts are raised only by the existing correlation rule and alert policy. This demo does not claim fall detection, medical emergencies, or real recognition.
